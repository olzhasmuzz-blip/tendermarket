# Issue tracker: Local Markdown

Задачи и спецификации этого репозитория хранятся в Markdown-файлах под `.scratch/`.

## Структура

- Одна функция или этап — одна папка `.scratch/<feature-slug>/`.
- Спецификация функции — `spec.md`.
- Задачи реализации — отдельные файлы `.scratch/<feature-slug>/issues/NN-<slug>.md`, номера начинаются с `01`.
- В начале задачи указывается `Status:` со значением одной из меток из `triage-labels.md`.
- Обсуждения добавляются внизу файла под заголовком `## Comments`.

## Операции трекера

- «Опубликовать в трекере» означает создать или обновить соответствующий Markdown-файл в `.scratch/`.
- «Получить задачу» означает прочитать названный путь или номер файла.
- Не создавать GitHub/GitLab issues, пока проект не переключён на внешний трекер.
