# Метки triage

Используются стандартные метки инженерных навыков:

| Метка | Значение |
| --- | --- |
| `needs-triage` | Нужно оценить и распределить задачу |
| `needs-info` | Требуется дополнительная информация |
| `ready-for-agent` | Задача готова к реализации агентом |
| `ready-for-human` | Требуется решение или работа человека |
| `wontfix` | Не планируется выполнять |

В строке `Status:` задачи используется одна метка из таблицы.
