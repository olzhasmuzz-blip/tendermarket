# ADR-0001: React web client, NestJS API, PostgreSQL

- Статус: принято
- Дата: 2026-09-25

## Контекст

Нужны полноценная веб-площадка и API для будущего Flutter-клиента. Основные правила доступа, подбора поставщиков, построчного расчёта предложений и сделок должны выполняться сервером и использоваться всеми клиентами.

## Решение

- Web-клиент: React + TypeScript + Vite, с использованием подготовленного Product Design starter для выбранного интерфейса.
- Сервер: NestJS + TypeScript, версионированный REST API и WebSocket для чата и уведомлений.
- Контракт: OpenAPI; Flutter-клиент и модели генерируются из API-контракта.
- Данные: PostgreSQL; Redis для очередей и временных задач; S3 API для медиа.
- Бэкенд остаётся модульным монолитом до измеримой необходимости разделять процессы.

## Последствия

Единый TypeScript-стек ускоряет разработку интерфейса и сервера. Независимый API позволяет Flutter-клиенту использовать те же бизнес-правила. Публичные web-маршруты можно позже дополнить SSR или prerender, если требования SEO подтвердят эту необходимость. Веб и мобильный интерфейсы не обязаны разделять UI-компоненты.
