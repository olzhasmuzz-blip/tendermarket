# Правила работы с репозиторием

## Agent skills

### Issue tracker

Задачи и спецификации ведутся локально в `.scratch/`. См. `docs/agents/issue-tracker.md`.

### Triage labels

Используются стандартные метки `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. См. `docs/agents/triage-labels.md`.

### Domain docs

Репозиторий использует single-context: корневой `CONTEXT.md` и `docs/adr/`. См. `docs/agents/domain.md`.

## Проект

Утверждённое продуктовое ТЗ находится в `.scratch/universal-marketplace/spec.md`. Перед изменениями доменной модели прочитай его, `CONTEXT.md` и относящиеся к задаче решения в `docs/adr/`.
